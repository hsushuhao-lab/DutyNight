# Signage assets

Diegetic signs are authored from game-approved text. Reference images establish mounting, spacing and finish only: never reproduce incidental generated Chinese text, reference room numbers, real security information or reference floor plans.

Signs must be attached to a solid frame/backplate; no emoji or camera-facing floating labels in production. Current zone builders use local browser text rasterization for approved Traditional Chinese copy, allowing installed system CJK fonts and preserving legibility. No third-party signage image has been imported.
