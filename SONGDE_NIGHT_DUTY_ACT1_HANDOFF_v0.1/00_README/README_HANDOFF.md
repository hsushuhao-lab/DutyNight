# SONGDE NIGHT DUTY — ACT 1 HANDOFF v0.1

## Working title
《松德值班夜：與避無可避的傳說》

## Scope of this package
This package covers **Act 1 only: 17:00–21:00, “Tonight Is Your Shift / 今晚輪到你”**.

Act 1 must feel like a believable, warm, ordinary psychiatric-hospital night shift for most of its runtime. The first unmistakable contradiction appears only at the end of the act and forces a player choice that determines the opening state of Act 2.

## Engine target
- Unreal Engine 5.x
- Windows PC first
- 1080p / 60 fps prototype target
- Later target: 1440p + DLSS

## Design principle
**Normality first. Horror second.**

The player should spend enough time learning the hospital, the duty routine, the nursing station, the computer workflow and the duty room that later changes feel personally wrong.

## What the Agent is allowed to build now
- First-person controller
- Basic interaction system
- Act 1 level blockout (fictionalized topology only)
- Duty workflow interactions
- Phone/call interaction
- Computer handoff UI mock
- Hidden state subsystem
- Warm lighting profile
- Act 1 dialogue/events
- End-of-act choice and save-state handoff

## What the Agent must NOT build yet
- Bed 33 full legend
- 00:33 ER supernatural event
- Skybridge legend
- Floor 6
- Ecological pond
- Full doppelgänger AI
- Chase/combat
- Final endings

## Restricted materials
Anything inside `02_ART/RESTRICTED_REFERENCE/` is reference-only and must not be shipped in the game or pushed to a public repository. Do not reconstruct exact real-world security, access-control or evacuation layouts. Use only high-level topology and visual language.
