# ACT 1 — Definition of Done

Act 1 is PASS only if all criteria below are met.

## Playability
- [ ] New Game enters Act 1 without editor intervention.
- [ ] Player can move, look, interact, and use doors/elevators.
- [ ] Player can complete the mandatory onboarding sequence.
- [ ] No soft-lock occurs if optional tasks are skipped.

## Mandatory sequence
- [ ] Collect duty-room key from the administrative office.
- [ ] Sign the duty log.
- [ ] Complete electronic handoff on an eligible workstation.
- [ ] Reach the closed psychiatric ward.
- [ ] Unlock the independent duty room.
- [ ] Make the bed (sheet + pillowcase interaction).
- [ ] Visit the nursing station and order dinner.
- [ ] Complete initial rounds across the ward cluster.
- [ ] Complete at least one routine nursing call.
- [ ] Complete at least one documentation action.
- [ ] Reach the late-evening priority-choice sequence.
- [ ] Trigger the first “You were just here” contradiction.
- [ ] Make one of the three end-of-act choices.
- [ ] Save resulting state for Act 2.

## Tone
- [ ] 17:00–20:45 is visually warm and non-horror.
- [ ] No monster, ghost, jump scare, or overt supernatural VFX appears.
- [ ] The end hook is subtle and plausible enough to be dismissed as fatigue or mistaken identity.
- [ ] The player feels that the hospital was a safe, familiar workplace before the contradiction.

## Performance
- [ ] 1080p prototype target: 60 fps average on the development laptop.
- [ ] No unnecessary loading of Second Campus, skybridge, hillside, pond or later-act assets.
