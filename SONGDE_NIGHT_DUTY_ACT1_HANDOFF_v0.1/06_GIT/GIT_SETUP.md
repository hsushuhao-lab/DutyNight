# Git / GitHub setup

Recommended repository: `songde-night-duty`
Recommended visibility during development: PRIVATE

## Commit policy
One testable change per commit.
Examples:
- `feat: initialize first-person controller`
- `feat: add duty-room key interaction`
- `feat: add electronic handoff mock`
- `level: add 4f ward blockout`
- `narrative: add act1 end contradiction`
- `test: verify act1 end-choice persistence`

## Do not commit publicly
- `02_ART/RESTRICTED_REFERENCE/`
- raw hospital photographs
- exact real floor/evacuation maps
- identifiable patient/staff information

## Suggested Git LFS patterns
- `*.psd`
- `*.blend`
- `*.fbx`
- `*.wav`
- large `*.png` / `*.tif` source textures as needed
