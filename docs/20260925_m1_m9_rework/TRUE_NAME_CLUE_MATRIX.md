# M1–M9 True Name and 員編 Clue Matrix

Canonical identity: 張守恆, 員編 MED-870409, 職級住院醫師. Player-facing terminology is 員工編號 or 員編; never 工號. The M1 clue is optional. All M3–M7 clues below are mandatory, and either valid M5 route must yield the same evidence.

| Milestone | Physical/source evidence | Required fragment | Gate |
|---|---|---|---|
| M1 | Optional 3F roster, correction-fluid trace: 住院醫師 張○○ | None required | Skipping does not block ending |
| M3 | 316 legacy terminal, index 1998-ER-0217: 張○○ and MED-87xxxx | surname 張; employee prefix MED-87 | Decode after recovering old ER registration slip |
| M4 | Inspect/collect old roster fragment at second-campus bed: 第一線：張 守 [墨漬] | given-name character 守 | Dialogue alone never grants it |
| M5 skybridge | Recover Annie-linked physical relic engraved 祝 守恆 醫師 1997 執業誌慶 | given-name character 恆 | Bridge remains valid until midpoint commitment |
| M5 pond/hillside | Equivalent recoverable Annie-linked physical relic | given-name character 恆 | Must be equivalent to bridge clue |
| M7 | B2 mirror-316 archive record | 張守恆; MED-870409; 住院醫師 | Full ID becomes explicit and required |
| M9 | Final 316 handoff form | Full name and full 員編 | Both must match; either mismatch fails |

`PersistentMemory.canReconstructTrueName()` requires surname, both given-name characters, MED-87 prefix, full MED-870409, and title. Final verification additionally requires exact name 張守恆 and exact employee number MED-870409. Preserve the evidence in the journal for review.

The special ER anomaly may use 無名氏. Later second-campus chest-pain patient is an ordinary registered patient, not another anonymous ghost case. The canonical anomaly phrase is 「李醫師，有一位無名氏資料卡住，麻煩你下來看一下。」 Never use 無民氏.
