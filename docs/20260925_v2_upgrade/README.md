# DutyNight 2.0 authority

This directory is the current implementation and release authority for the playable Three.js game in `prototype/`.

## Precedence

1. Newest explicit user directions and their linked appendices, including `ANNIE_VISUAL_REWORK_SPEC.md`.
2. `MASTER_UPGRADE_DIRECTIVE.md` and its acceptance contracts.
3. Current executable behavior in `prototype/`.
4. Automated and browser QA in `QA_V2.md`.
5. The V2 narrative, indoor-world, art-direction, and Annie bibles in this directory.
6. `docs/20260925_m1_m9_rework/` and earlier documents, as historical scope and rationale.

The old Act 1-only statements are historical. They do not remove Bed 33, Phantom 6F, B2, the identity takeover, or the M9 handoff. V2 retains the established M1–M9 mystery and changes the playable world to an enclosed indoor route.

The concept images under `art_reference/` define mood, material, lighting, and composition. Their generated labels, clocks, floorplans, exterior routes, and patient details are not canon. `ANNIE_FINAL_IDENTITY.md` overrides the superseded human-doctor depiction.
